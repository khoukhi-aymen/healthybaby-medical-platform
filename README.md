# HealthyBaby Clinic System

This project is a complete web platform developed for **Healthy Baby Clinic** to manage online consultations, appointment scheduling, and medical content distribution.

## 🌐 Main Features

- Secure user roles: Patients, Doctors, Administrators
- Online appointment booking with pre-consultation questionnaire
- Personalized schedules for each doctor
- Automated email notifications and reminders
- Multilingual support: Arabic and English
- Medical blog module with categorized articles
- Responsive design (Desktop & Mobile)
- Admin dashboard for full management

## 🛠️ Technologies Used

- **Frontend**: EJS (Embedded JavaScript)
- **Backend**: Node.js + Express.js
- **Database**: MongoDB
- **Security**: Session-based authentication, CSRF protection
- **Deployment**: To be determined (VPS or cloud host)

## 👤 Roles

- **Patients**: Browse medical blogs, book consultations online
- **Doctors**: Manage appointments and publish medical content
- **Admins**: Oversee the platform, manage users and content
